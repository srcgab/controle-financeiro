Sobre o Projeto

Objetivo

Oferecer uma ferramenta simples e eficiente para controle de finanças pessoais, ajudando usuários a organizarem suas receitas, despesas e metas financeiras.

Tecnologias

  • Angular 17+
  • TypeScript
  • CSS3
  • JSON Server (Development)

Funcionalidades

  • Controle de receitas e despesas
  • Dashboard interativo
  • Metas financeiras
  • Perfil de usuário
  • Relatórios por período
